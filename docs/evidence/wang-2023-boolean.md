# Can ChatGPT Write a Good Boolean Query for Systematic Review Literature Search?

**Source:** 2023; peer-reviewed study

## Bibliographic information

- **Source category:** peer-reviewed-study
- **Record type:** conference-paper
- **Notes:** Benchmarked ChatGPT prompt variants on CLEF TAR and seed-study collections using PubMed retrieval. Prompt-only queries often had higher precision but materially lower recall than human queries; guided seed-based construction improved recall. Generated MeSH terms were frequently invalid and repeated prompts were variable. The tested January 2023 ChatGPT snapshot and PubMed benchmarks limit generalization.
