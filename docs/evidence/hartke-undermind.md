- **Notes:** Vendor benchmark of an early Undermind implementation that searched 2.3 million arXiv papers using GPT-4. It compares approximately 300 late-2023 user queries with five GPT-4-generated Google Scholar keyword searches per query. Relevance for both systems was assigned by Undermind's own classifier; a separate manual check covered 432 classified papers.
