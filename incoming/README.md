# Incoming papers

Place source files here for review and processing. Do not treat a file in this folder as structured evidence until its metadata and findings have been reviewed and represented in `data/`.

PDFs in `papers/` are ignored by Git by default. Evidence records keep DOI or URL references where available, plus the local filename used during extraction.

When only an abstract is available, a saved PubMed XML record may be placed in `papers/`. Mark any resulting source and claim records as abstract-only and do not infer details that require the full paper.
